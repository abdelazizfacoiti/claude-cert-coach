# CCAO-F Associate Foundations (non-coder; weights: third-party, verify)
Prompting&Task 14 | Output Eval&Validation 21 | Product&Model Selection 12 | Workflow Integration 16
Config&Knowledge Mgmt 12 | Governance/Risk/Responsible Use 15 | Troubleshooting&Optimization 10
## Signals: pattern -> domain -> better
- Vague ask -> Prompting -> state goal, audience, format, constraints, examples
- Answer accepted unchecked -> Output Eval -> verify facts/sources, ask for reasoning/citations
- Same context retyped -> Config&Knowledge -> Projects / saved instructions / files
- Sensitive data pasted -> Governance -> redact PII, follow policy
- Wrong-fit model/tool -> Product Selection -> match model/feature to task
- Bad result, user restarts -> Troubleshooting -> iterate: say what's wrong, add constraints
- Manual repeated task -> Workflow Integration -> template/automate
